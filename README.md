# Week 4 Task – Medical Writing Style Guide

## Overview
This repository contains my Week 4 internship submission: a **Medical Writing
Style Guide** that gives clear instructions on tone, language, structure and
formatting for medical documents aimed at both expert and general audiences.

## Contents
- `Medical_Writing_Style_Guide.docx`: the full style guide

## Guide Structure
- Introduction (purpose, scope, audiences)
- Voice and Tone
- Language Guidelines (clarity, jargon, abbreviations, drug names,
  bias-free language, numbers and statistics, commonly confused terms)
- Document Structure (IMRaD, titles, abstracts, reporting guidelines)
- Formatting Standards
- Citations and References (AMA numbered style)
- Visual Data Representation
- Ethics and Integrity
- Best Practices and Workflow (examples, checklist, quick reference card)

## Approach
- Researched established standards, including the AMA Manual of Style,
  ICMJE recommendations, CONSORT, PRISMA and federal plain-language guidance
- Synthesized shared rules and added my own recommendations
- Included before-and-after examples, tables and a checklist so the guide
  works as a standalone reference
